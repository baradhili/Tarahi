# Tarahi brand kit

The project's own artwork, posted by the maintainer in #372 and kept here as the source for app icons and listings (the ArtCraft Launcher catalog entry, for one).

| File | What |
|---|---|
| `tarahi-app-button.svg` | App icon, dark (1024 × 1024) |
| `tarahi-app-button-light.svg` | App icon, light (1024 × 1024) |
| `tarahi-logo.svg` | Wordmark, dark (480 × 190) |
| `tarahi-logo-light.svg` | Wordmark, light (480 × 190) |

The app icons carry a subtle SVG animation; renderers without animation support draw their still frame. Licensed like the project (MIT OR Apache-2.0).
